The oracle set provides a quantitative yardstick that the public instances

The clean/dirty mirror pair re-checks the
$\mathrm{Tr}=\mathrm{Vol}+\mathrm{Dt}$ billing semantics on a minimal example:
both instances spill the same volume $\mathrm{Vol}=1{,}024$ with the same
spill count of two, yet the clean variant is fully backed ($\mathrm{Dt}=0$,
$\mathrm{Tr}=1{,}024$) while the dirty variant is fully generated
($\mathrm{Dt}=1{,}024$, $\mathrm{Tr}=2{,}048$), doubling the billed traffic
exactly; the production solver and the predecessor portfolio tie on both.
