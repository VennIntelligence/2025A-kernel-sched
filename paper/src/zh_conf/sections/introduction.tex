\section{引言}\label{sec:intro}
NPU 编译器将每个核函数下沉为数千个微操作，这些微操作运行在异构流水线上，并经由多个软件管理的片上缓存交换数据。对此类核函数进行调度，意味着同时确定微操作 DAG 的合法拓扑序、每个驻留缓冲区的连续物理地址，以及容量不足时的溢出计划。合法性约束本身留下巨大的决策自由度：缓冲区在何时分配、使用与释放，既决定必须离开片上的字节总量，也决定哪些数据被选中驱逐；仅凭逻辑活跃峰值无法刻画地址碎片、下次使用距离与非对称溢出代价这三类因素。

基准对有输入备份和生成且无备份的缓冲区分别收取一次与两次传输代价。若总溢出体积为 $\mathrm{Vol}$，其中生成缓冲体积为 $\mathrm{Dt}$，则 $\mathrm{Tr}=\mathrm{Vol}+\mathrm{Dt}$。因此流量变化必须同时从总溢出量与生成附加量解释；正式定义与紧界见第~\ref{sec:formulation}~节，完整证明见补充材料第 2.1 节。

本文将拓扑序构造与物理溢出规划解耦，并以机器可验证的精确规划器为可扩展启发式提供量化标尺（图~\ref{fig:bridge-zh}）。生产求解器以\textbf{依赖前沿}序避免就绪前驱组饥饿，并在少量结构序、地址/驱逐策略与重载窗口之间按真实 P2/P3 目标选择。固定序研究 oracle 则以加权驻留间隙模型给出流量下界；当所选间隙可连续打包且标准评测值达到下界时，得到固定序流量证书。离线修复与精确规划均作为独立研究工具报告，不进入默认流水线；完整求解过程见补充材料第 3 节。

本文的主要贡献有三：(1) 可扩展的依赖前沿调度器与按真实目标选优的溢出规划组合；(2) 可由连续地址工件升级为固定序流量证书的加权驻留间隙下界；(3) 以 $\mathrm{Tr}=\mathrm{Vol}+\mathrm{Dt}$ 为主线、严格区分生产求解器、修复个案与精确 oracle 的审计式实验体系。在六个公开实例上，生产求解器取得 P2 五胜一平和 P3 时间五胜一负；Conv\_Case0 的固定序 oracle 认证 57{,}408 字节，并揭示相对旧 P1 序的 $29.6\%$ 固定序差距。非统一修复与内部合成结果仅作边界明确的附加证据，详见第~\ref{sec:experiments}~节及补充材料第 4 节。
